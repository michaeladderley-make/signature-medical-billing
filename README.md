# Signature Medical Billing

Next.js prototype of the Signature Medical Billing work hub. The layout follows the Figma frame. Color and type come from `design.md`.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Inter and JetBrains Mono load through `next/font`. Theme tokens live in `src/app/globals.css`. UI components live in `src/components/ui`.
